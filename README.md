# Restaurant-Menu-Application
Creating Restaurant Menu Web Application by using-HTML, CSS&lt; Bootstrap, JavaScript.

Key Features:
1. Category Based Filtering:
The menu is divided into categories (e.g., starters, mains, desserts) to make it easier for customers to find what they're looking for.

2. Search Functionality:
Users can search for specific dishes based on keywords like the dish name, category, or ingredients.

3. Interactive Menu Cards: 
Each dish is displayed with an image, description, and price, allowing customers to get a visual and textual representation of what they are ordering.

4. Responsive Design: 
The app is fully responsive, ensuring it works smoothly on various devices, from desktop screens to mobile phones.

I built this app using:
HTML, CSS, and JavaScript for the front-end to create a dynamic and responsive user interface.
Bootstrap for styling and ensuring mobile compatibility.
JavaScript for functionality, including filtering, searching, and rendering dynamic menu items based on user input.
DOM Manipulation to update the content dynamically, such as adding items to the menu or filtering based on user input."
